# SignalPoint

El mercado en palabras simples. Un briefing de eventos de mercado y economía: qué pasó, quién está expuesto, qué mirar después y qué no se sabe, con la fuente a un clic.

**No es tiempo real. No es asesoría de inversión.**

Sitio: https://martinfgaleano-crypto.github.io/signalpoint/

## Qué hay aquí
| Carpeta | Qué es |
|---|---|
| `index.html`, `nuevo/` | Página principal y portada alterna |
| `glosario/`, `herramientas/`, `aprende/` | Glosario, calculadoras y cursos |
| `tools/` | Scripts de Python que redactan los briefs, bajan datos de mercado y arman las páginas |
| `.github/workflows/` | Los dos procesos automáticos (briefs y datos) |
| `backend/sql/`, `supabase/functions/` | Base de datos y funciones (inicio de sesión, portafolio, resumen por correo) |

La rama `main` es el sitio publicado. Las ramas `data` y `drafts` las escribe el proceso automático.

Para trabajar en el proyecto, lee `CLAUDE.md`.
